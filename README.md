# Build Applications with GitHub Copilot Agent Mode

<img src="https://octodex.github.com/images/Professortocat_v2.png" align="right" height="200px" />

This repository contains the OctoFit Tracker multi-tier application scaffold.

## Stack

- Frontend: React 19 + Vite + React Router + Bootstrap
- Backend: Node.js + Express + TypeScript + Mongoose
- Data: MongoDB on localhost port 27017

## Run locally

- Backend: `npm --prefix octofit-tracker/backend run dev`
- Frontend: `npm --prefix octofit-tracker/frontend run dev`

The frontend serves on port 5173 and the backend on port 8000.
